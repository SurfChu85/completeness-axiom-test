# Which Completeness Axiom Are You?

A completely rigorous personality test with absolutely no psychological validity.

Inspired by the various equivalent formulations of the completeness of the real numbers, this quiz determines which "completeness axiom" best matches your personality.

**[Take the test here](https://script.google.com/macros/s/AKfycbzgnh6E-gQTmZ2-CeXk0e1h3peQWpkOyL6PRPfDQrCz6dbHAbSnvF5W8yjMWnRpUwZj/exec)**

## The Results

The quiz assigns you one of eight mathematical personalities (list is taken from [this wikipedia page](https://en.wikipedia.org/wiki/Completeness_of_the_real_numbers)):

- Least Upper Bound Property
- Dedekind Completeness
- Cauchy Completeness
- Nested Intervals Theorem
- Open Induction Principle
- Monotone Convergence Theorem
- Bolzano–Weierstrass Theorem
- Intermediate Value Theorem

Of course, these are mathematical formulations/theorems associated with the completeness of the real numbers, not actual personality types.

## Privacy

This quiz does not collect names, email addresses, or other personally identifying information.

Responses are not stored or transmitted for scoring. The result is calculated locally in the respondent's browser.
